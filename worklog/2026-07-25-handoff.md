# Handoff — YouTube Language Sidebar extension

Location: `/Users/flanneryjefferson/Projects/passage/yt-lr-extension/` (unpacked Chrome extension, standalone — NOT part of the PassageCLI Swift package).

## What this is
Language-Reactor-style subtitle sidebar for **YouTube + Netflix**. Sentence-chunked subtitles, click-to-seek, hover = English translation, and **star a line to save its text + a real audio clip** (WAV) to IndexedDB → "Saved" tab.

## Architecture
- `core.js` — site-agnostic UI/state/logic. Driven by `NS.adapter`.
- `youtube.js` / `netflix.js` — per-site adapters (set `NS.adapter`, loaded before `core.js`).
- `inject.js` (YouTube MAIN world) — drives player to load track, intercepts `/api/timedtext`, re-serves as `json3`. Caches json3 **text** per lang and serves on `SELECT_TRACK` (never re-fetches — YT URLs 404/empty on refetch).
- `netflix-inject.js` (Netflix MAIN world) — hooks `JSON.parse` to grab manifest → subtitle track URLs; seeks via Netflix player API.
- `captions.js` — `parseJson3` (word-timed → sentence chunks), `parseJson3Cues`, `parseWebVTT`, `parseTTML`.
- `audio.js` — `AudioCapture`: ring buffer + WAV. `ensureFromElement()` (YouTube tap) / `ensureFromStream()` (Netflix tabCapture). `encodeWav`.
- `pcm-worklet.js` — AudioWorklet, passthrough + mono PCM to ring buffer.
- `db.js` — IndexedDB (`ylr`/`clips`), under the SITE origin.
- `background.js` — service worker: toolbar click → `tabCapture.getMediaStreamId` → sends `ENABLE_CAPTURE` to tab.
- Manifest v3. Reload via `chrome://extensions` ↻ after every change. `node --check src/*.js` to syntax-check (can't run DOMParser/browser APIs in node).
